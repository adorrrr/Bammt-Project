# 🐟 Gangchill Project Index & Delivery Overview

This document provides a concise roadmap and feature index of the Gangchill frontend application for stakeholders and clients.

## 📌 Routes & Screen Directory

| Route | Page Name | Key Features |
|---|---|---|
| `/` | **Landing Page** | Full-canvas editorial hero, 3 Core Action Cards (Buy/Sell/Invest), Featured Today (আজকের সংগ্রহ), Upcoming Stock (সামনে কী আসছে?), Procurement Fund Highlight. |
| `/buy` | **Wholesale Stock Board** | Filterable bulk fish inventory, organic shoreline photo cards, quantity/price stats, Corporate Requirement Modal. |
| `/stock/:slug` | **Stock Detail Page** | Full specifications, origin & harvesting cluster info, packaging & logistics details, requirement intake flow. |
| `/sell` | **Fish Supply Submission** | Dual entry for fishermen/farmers and bulk traders, step-by-step Bangla submission form with cold-chain pickup scheduling. |
| `/invest` | **Procurement Fund Plans** | Targeted seasonal fish procurement fund opportunities, transparency metrics, target ROI, timeline & investment intake. |
| `/invest/:slug` | **Investment Plan Detail** | Procurement timeline, supply-chain flow diagram, risk management & investor safety notes. |
| `/contact` | **Contact & Sourcing Hubs** | Head office info, coastal & river sourcing hub network, direct inquiry messaging form. |

## 🎨 Visual System Highlights
- **Canvas**: Ice White (`#F4F7FB`) & Clean White (`#FFFFFF`)
- **Typography**: Deep Midnight Navy (`#0B192C`) + Bengali Serif Titles
- **Accents**: Deep Navy (`#0B192C`) & Royal Sapphire Blue (`#1D4ED8`) with Ocean Cyan (`#0284C7`) highlights — "Liquid Glass" translucent surfaces with backdrop blur
- **Card System**: Organic Shoreline Curves with authentic Bangla taglines
- **Micro-Interactions**: Ambient water-light background + 600ms point/tap ripple

## 🛠️ Build Status
- **Tech Stack**: React 18, TypeScript, Vite 5, Tailwind CSS
- **Build Status**: Verified `0 errors` on `npm run build`
